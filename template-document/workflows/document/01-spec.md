# 01 · spec（章节大纲）

文档撰写闭环 step 01。

## 触发

新文档 / 新章节启动。

## 产出

`specs/active/YYYY-MM-DD-<slug>.md` 含：

- 文档 / 章节标题
- 受众
- 内容大纲（H1/H2/H3 层级）
- 验收点（页数 / 字数 / 必含图件 / 关键引用 / 完成判定）
- 资料来源（raw/ 下文件 + 现有 wiki/ 页面）

## 边界

- 一个 spec 一个章节单职责，避免 scope creep
- 多章节同时启动 → 拆成多个 spec

## 完成判定

- 大纲被用户认可
- 资料齐备（已 ingest 到 wiki/source-summaries/）
- 验收点可量化或可主观判断
